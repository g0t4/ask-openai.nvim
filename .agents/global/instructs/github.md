## GitHub tips

- The Github CLI is authenticated so you don't have to fetch web pages, i.e. `gh pr list` or `gh issue view 12`
- Raw markdown readmes are much more concise: <https://raw.githubusercontent.com/openai/evals/refs/heads/main/README.md>
  rendering it to html is not: <https://github.com/openai/evals>
- Same with raw code files <https://raw.githubusercontent.com/g0t4/dotfiles/refs/heads/master/install/symlinks.fish>
  instead of <https://github.com/g0t4/dotfiles/blob/master/install/symlinks.fish>
